# Ананасовый улун

Карточка товара интернет-магазина Teaboom. На странице фото, категория, название, выбор фасовки, артикул, старая и текущая цена, кнопка «В корзину» и короткое описание.

Четыре фасовки: 100, 500, 1000 и 5000 г. По умолчанию выбраны 100 г. Смена фасовки обновляет артикул, цены и подпись кнопки. Кнопка ничего не отправляет.

## Что нужно

Node.js и npm. Sass ставится вместе с зависимостями проекта и глобально не требуется.

## Запуск

```bash
npm install
npm run build
```

Откройте `index.html` в браузере.

Собранный файл `assets/styles/styles.css` уже лежит в репозитории, поэтому после клонирования страница открывается и без сборки. `npm run build` заново собирает его из SCSS.

Пока правите стили, запустите слежение:

```bash
npm run dev
```

Команда следит за `assets/styles/main.scss` и перезаписывает `assets/styles/styles.css`. Обновите страницу в браузере, чтобы увидеть правку.

## Состав

- `index.html` — страница
- `assets/styles/` — исходники SCSS и собранный CSS
- `assets/scripts/main.js` — переключение фасовки
- `assets/images/` — фото товара
- `assets/fonts/OpenSans/` — шрифт Open Sans и лицензия OFL
